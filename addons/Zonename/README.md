# Zonename (VanaDreams)

Ashita v4 addon by Xenonsmurf, with Japanese support and other improvements by onimitch, ported from Windower. Based on the upstream 2.3 release and the launcher-installed Lua baseline. Original and dependency licenses are included.

This version uses the destination carried by the login/zone packet instead of waiting one second and reading party memory. The banner waits until the player can render. Existing settings and the /zonename reload and /zonename test commands are preserved.

Upstream: https://github.com/onimitch/ffxi-zonename
